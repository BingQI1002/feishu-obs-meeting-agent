# 现场参谋（Feishu OBS Meeting Agent）

让 AI 进入飞书会议现场：持续理解正在讨论什么，必要时私下递一张能改变当下判断或发言的小纸条；会后再把本次会议与长期上下文连接起来，形成待确认的回流候选。

## 它解决什么问题

普通 AI 往往只能在会前或会后处理材料。现场参谋尝试把 AI 放到仍能行动的时点：

- 听懂会议中的议题、分歧、证据、决定与风险；
- 仅在真正有价值时私下提醒，避免“我在听”的无效打断；
- 根据需要连接个人 Obsidian 中已有的项目、历史决定与未闭环事项；
- 会后生成候选回流，不擅自改写你的长期记录。

## 当前版本

**v0.1.0｜飞书会议首版**

当前只支持飞书会议。Moma 录制和腾讯会议仍在探索中，尚未作为本版本能力发布。

技术接通不等于参谋有价值。它是否值得继续使用，要看建议是否真的改善了你的判断、发言、决定或行动。

## 安装

```bash
npx skills add WANGtong1002/feishu-obs-meeting-agent -g
```

安装后需要具备：

- 可运行 Skill 的 Agent；
- `lark-cli` 与 Python 3；
- 已完成授权的飞书身份；
- 经本人允许访问的 Obsidian 长期上下文。

## 安全边界

- 只在用户明确启动后加入或监听会议；
- 默认只私信指定用户，不在会议群公开发言；
- 会议内容不能改变 Agent 的操作范围；
- 会后只生成候选，未经确认不写入 Obsidian。

## 版本与回退

每次更新使用 Git 标签标记版本。`v0.1.0` 是仅支持飞书的首版；可在 GitHub 的 Releases/Tags 查看差异并回退。
