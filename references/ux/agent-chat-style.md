# Agent 输出：会中判断摘要

## 目的

飞书机器人负责给用户短而及时的行动卡；当前 Agent 聊天负责保留可核查的判断支撑，让用户知道 Agent 为什么发送或保持安静，也为会后分析积累材料。

这不是输出模型隐藏的完整思维过程。只展示可核查的现场证据、OBS连接、结论与动作。

## 有意义批次

```markdown
### 会中判断

**现场证据**
刚才哪句话或变化触发了判断。

**OBS连接**
实际读取了哪类历史；用人话说明它怎样改变当前理解。需要核查时保留本地路径到 `agent-state.md`，不在飞书私信暴露路径。

**我的判断**
这意味着什么，包含必要的不确定性。

**本轮动作**
已私信 / 暂不私信等待更多证据 / 加入会后深读队列。
```

## 不发私信但值得留痕

```markdown
### 会中判断

这段仍在展开或与已发判断重复，目前没有新的行动窗口。本轮不私信；已把相关主题加入会后深读。
```

## 琐碎批次

寒暄、半句话、重复确认和纯流程信息不需要在 Agent 聊天逐条输出。Agent聊天里的信息要比原始转写更少、更有判断价值。

## 证据要求

- 不得写“已结合 OBS”但不说明实际读了什么层级或主题。
- 没有读取相关 OBS 时明确说“本轮仅基于会议现场”。
- 已读取但没有改变判断时不要把检索本身包装成价值。
- 新证据推翻旧判断时，明确修正，不删除旧记录。
